# Pizza Luka — Restaurant Website

A responsive, editorial-style website for Pizza Luka in Vang Vieng, Laos. Built with plain HTML, CSS and JavaScript so it can be hosted easily on GitHub Pages or any static web host.

## Included
- Responsive home page with story, menu highlights, gallery and visit/contact sections
- Mobile navigation and accessible skip link
- Click-to-call and email contact links
- Apple Maps directions link to the supplied Pizza Luka location
- SEO description, responsive metadata and reduced-motion support

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Publish with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/(root)`, then save.
4. GitHub Pages will provide the public site URL after deployment completes.

This implementation is currently on `feature/pizza-luka-restaurant-site`. Review and merge it into `main` before enabling Pages.

## Content to verify before launch
The restaurant should confirm the current menu and prices, opening hours, exact street address, reservation workflow, logo, official social links and photo usage permissions. The page asks visitors to contact the restaurant to confirm opening hours and menu availability rather than publishing unverified details.

## Customisation
- Edit copy and sections in `index.html`.
- Change colours, typography and layout in `styles.css`.
- Update mobile navigation behaviour in `script.js`.

Food and restaurant photography currently uses remote Unsplash image URLs. Replace these with approved Pizza Luka photographs before production launch for the most authentic result.
